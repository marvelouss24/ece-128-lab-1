# ece-128-lab-1

### Project Description
Design and implementation of an 8-to-1 Multiplexer using behavioral, structural, and dataflow modeling in Verilog using Vivado and a Basys 3 FGPA board. 

### Instructions

Run the bitstream to use the FPGA with the code. 3 of the switches are the selectors and the first 8 from right to left are the inputs. Selecting a specific selector combination (correlation to 3 bits, 000 -> 111) will have the LED output equal to a specific switch. For example keeping all 3 selector switches OFF will have the right most LED equal to the output. Turning on the switch will turn on its LED
